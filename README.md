## Игровая студия

В корне репозитория установлен фреймворк [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) 1.3.0: 78 скиллов, 49 агентов и вспомогательные скрипты в `.claude/`. Агенты используют его для любой работы над играми — правило и особенности работы в облачной песочнице записаны в [AGENTS.md](AGENTS.md).

Чтобы начать, напишите агенту «сделай игру про …» или `/prototype <идея>`. `/start` проведёт по шагам с нуля, `/next-step` подскажет следующий шаг.

Документация фреймворка — в [README оригинала](https://github.com/Donchitos/Claude-Code-Game-Studios/blob/abc0de79d6ceb0b5d7aa693945849b3937afbe6a/README.md). Происхождение файлов, лицензия и порядок обновления — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
